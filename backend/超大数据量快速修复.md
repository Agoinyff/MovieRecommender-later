## ⚙️ 可选配置

### 调整采样率（速度 vs 质量）

编辑这两个文件中的 `SAMPLE_RATE`：
- `src/main/java/.../service/RecommendationService.java`
- `src/main/java/.../service/DataModelWarmer.java`

```java
// 默认配置（推荐）
private static final double SAMPLE_RATE = 0.5; // 50%数据，8-10分钟

// 其他选项：
// 1.0  = 全部数据（15-20分钟，质量最佳）
// 0.3  = 30%数据（5-6分钟，质量良好）
// 0.1  = 10%数据（2-3分钟，质量可用）
```

### 调整内存大小

编辑 `start.bat` 或 `start.sh`：
```bash
-Xmx4096m  # 当前4GB
-Xmx6144m  # 可改为6GB（如果使用100%数据）
```

## 💡 核心改进

### 1. JDBC流式查询（快5-10倍）
```java
// 旧：JPA - 每5000条47秒
Page<RatingEntity> page = repository.findAll(...);

// 新：JDBC - 每100万条5-6秒
ResultSet rs = stmt.executeQuery("SELECT userID, movieID, preference...");
while (rs.next()) { ... }
```

### 2. 异步预热（用户无感知）
```java
@EventListener(ApplicationReadyEvent.class)
@Async
public void warmUpDataModel() {
    // 后台自动加载，不阻塞用户请求
}
```

### 3. 智能采样（速度翻倍）
```sql
-- 加载最近50%的数据（最新数据更有价值）
SELECT * FROM movie_preferences 
ORDER BY timestamp DESC 
LIMIT 16000000
```
