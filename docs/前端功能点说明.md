# MovieRecommender 前端功能点说明

## 1. 文档目的

本文档用于说明当前项目前端（`frontend/`）已实现的核心功能点，便于：

- 产品/项目经理做功能清单确认
- 前后端联调时快速定位页面与接口
- 测试同学设计用例与回归范围

---

## 2. 前端整体功能结构

当前前端基于 Vue 3 单页应用，包含 6 个主路由页面：

1. 首页（`/`）
2. 电影库（`/movies`）
3. 个性化推荐（`/recommendations`）
4. 我的评分（`/profile`）
5. 系统监控（`/metrics`）
6. 关于系统（`/about`）

并通过全局导航栏、统一 API 层、状态管理（Pinia）进行支撑。

---

## 3. 页面级功能点说明

## 3.1 首页（HomePage）

**功能点：**

- 展示系统定位与价值主张（AI 个性化推荐）。
- 展示推荐算法能力说明（用户协同、物品协同、Slope One）。
- 提供两个主 CTA：
  - 跳转“电影库”
  - 跳转“个性化推荐”

**用户价值：**
- 新用户可快速理解系统用途并进入核心流程。

## 3.2 电影库（MoviesPage）

**功能点：**

- 电影列表分页浏览（默认分页查询）。
- 关键词搜索（输入框回车或点击“搜索”）。
- 清空搜索关键字并恢复默认列表。
- 电影总量展示（顶部统计 badge）。
- 点击电影卡片打开详情弹窗。
- 支持加载中、错误态、空数据态。
- 分页切换后自动平滑滚动到顶部。

**用户价值：**
- 支持“先检索再查看详情”的高频浏览路径。

## 3.3 个性化推荐（RecommendationsPage）

**功能点：**

- 推荐参数配置表单：
  - 用户 ID
  - 推荐策略（`USER_BASED` / `ITEM_BASED` / `SLOPE_ONE`）
  - 返回条数（1~50）
- 根据策略动态展示算法说明文案。
- 提交后调用推荐接口并渲染推荐结果卡片。
- 推荐结果支持评分/分数可视化展示（MovieCard 的 `show-score`）。
- 点击推荐电影可查看详情弹窗。
- 支持未查询欢迎态、加载态、错误态、空结果态。

**用户价值：**
- 允许业务/用户按策略对比推荐结果，满足算法展示与体验验证。

## 3.4 我的评分（UserProfilePage）

**功能点：**

- 输入用户 ID 查询评分记录。
- 展示评分统计：
  - 评分总数
  - 平均评分
  - 高分电影数量（≥4 星）
- 展示用户评分表格（含电影信息）。
- 从评分表中点击电影，打开详情弹窗。
- 提供“获取推荐”快捷入口跳转推荐页。
- 支持欢迎态与加载控制。

**用户价值：**
- 让用户直观看到个人评分画像，并形成“评分 → 推荐”的闭环。

## 3.5 系统监控（MetricsPage）

**功能点：**

- 健康状态展示：
  - 服务状态徽标
  - 评分总数
  - 运行时长
- 内存监控卡片：总内存、已用、空闲、最大内存。
- 缓存统计面板展示与刷新。
- 一键清理缓存。
- 手动刷新所有指标。
- 自动刷新开关（5 秒轮询）。
- 显示“最后更新时间”。

**用户价值：**
- 便于开发/运维快速观测系统运行状态与缓存命中表现。

## 3.6 关于系统（AboutPage）

**功能点：**

- 展示系统介绍、技术栈、推荐算法说明与使用引导（信息展示型页面）。

**用户价值：**
- 提供面向业务方和新成员的“产品说明入口”。

## 4. 全局与公共能力

## 4.1 全局导航与状态

- 顶部导航栏支持 6 大页面快速切换。
- 当前路由高亮显示。
- 导航栏中展示系统健康状态徽标。
- 定时健康检查（30 秒轮询）更新状态。

## 4.2 路由与页面体验

- 使用懒加载路由组件降低首屏包体积。
- 路由切换时自动更新浏览器标题（`页面名 - 电影推荐系统`）。
- 支持滚动位置处理（新页面默认滚到顶部，回退保留位置）。

## 4.3 通用状态处理

- 主要业务页面均具备：加载态 / 错误态 / 空态。
- 推荐和电影列表页面均提供动效过渡（Transition / TransitionGroup）。

## 4.4 电影详情与评分交互组件

- `MovieDetailDialog`：在多页面复用的电影详情弹窗。
- `MovieCard`：统一电影信息展示卡片（可选显示推荐分数）。
- `UserRatingsTable` / `RatingStars` / `RatingDialog`：评分展示与交互相关组件。

## 5. 前端接口能力映射（按功能域）

## 5.1 电影域

- `GET /movies`：电影分页列表
- `GET /movies?query=xxx`：关键字搜索
- `GET /movies/{id}`：电影详情

## 5.2 推荐域

- `GET /recommendations`：个性化推荐
- `getPopularMovies`：当前以前 N 部电影作为临时“热门”实现（预留可替换后端热门接口）

## 5.3 评分域

- `POST /ratings`：提交评分
- `GET /ratings/user/{userId}`：查询用户评分记录

## 5.4 监控与健康域

- `GET /health/status`：服务健康状态
- `GET /health/rating-count`：评分总数
- `GET /metrics/memory`：内存指标
- `GET /metrics/cache`：缓存统计
- `GET /metrics/cache/clear`：缓存清理

---

## 6. 前端非功能特性

- 响应式适配：导航和页面布局在中小屏下有适配策略。
- 视觉风格：玻璃拟态、卡片化布局、渐变主题。
- 可维护性：
  - API 分层（`api/*.js`）
  - 页面/组件拆分（`views/` + `components/`）
  - Pinia 状态集中管理（电影列表域）
