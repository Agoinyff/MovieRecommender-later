# 本次改动说明

## 1. 改动背景

本轮改动围绕以下目标展开：

- 后端采用 `JWT + 自定义注解 + 拦截器` 的轻量鉴权方案。
- 增加登录、注册、当前登录用户能力，并区分普通用户与管理员角色。
- 前端围绕当前登录用户工作，同时保留“输入用户 ID 查询推荐”的能力，但仅管理员可见。
- 将“我的评分”升级为真实个人中心。
- 电影详情页加入评分卡片、推荐联动和底部横向推荐。
- 保留并正式化“个性化推荐”页面。
- 将系统监控能力收口为管理员入口。
- 前端保持现有布局样式不变。

## 4. 为什么会出现中文注释和接口文档丢失

这是我这次改动中的问题，原因有两点：

- 为了处理运行时错误和编码损坏文件，我直接重写了部分 Java 文件。
- 在重写过程中，我优先保留了可运行逻辑，没有把原来的中文 JavaDoc 和 Swagger 注解完整迁回。

这不是你原项目设计上的问题，是我在重构和修错时把“代码可运行”放在了“注释和接口文档完整恢复”前面，导致文档层内容缺失。
